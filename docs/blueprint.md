# **App Name**: ProductPulse

## Core Features:

- Product Listing: Display a list of available products with key details like name, category, rating, and price.
- Category-based Recommendations: Recommend products to users based on category that is selected, 
- Product Detail View: Show detailed information about a specific product, including related recommendations.
- KNN Based Recommendation: Recommends similar items from within a category. Uses ratings, price and users purchased for recommendations.
- Complementary Product Recommendations: Recommends products in categories typically bought with the current item.
- Product Management: Allow administrators to add and remove products from the dataset.

## Style Guidelines:

- Primary color: Deep blue (#3F51B5), evoking trust and reliability.
- Background color: Very light blue (#F0F2F5), for a clean, professional backdrop.
- Accent color: Soft purple (#9575CD), providing a modern, high-end feel for interactive elements.
- Headline font: 'Space Grotesk', sans-serif, giving the app a modern, technological look.
- Body font: 'Inter', sans-serif, is paired for body text to increase readability in longer paragraphs.
- Use clear, consistent icons throughout the app to aid navigation and indicate product categories.
- Employ a clean, grid-based layout to ensure that product listings and recommendations are well-organized and easy to navigate.
- Incorporate subtle transitions and hover effects to provide feedback and enhance user interaction, avoiding distracting or slow animations.
